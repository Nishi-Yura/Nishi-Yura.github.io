## 2. 10件から取り出した共通ルール（全ページ必須）

1. **最初の画面でスコアが読める。** 大会名・日付 → 両チーム名とスコア → マップごとの勝敗 の順（VLR / HLTV / FotMob）。
2. **見出しは小さく、数字は大きく。** セクション見出しは小さい大文字ラベル。大きくするのはスコアと主要な数字だけ（VLR / FotMob）。
3. **色はデータにだけ使う。** 勝ち負けは文字色か細い帯で示す。装飾のための色・グラデーションは使わない（HLTV / Opta / F1）。
4. **ドラフトは順番付きで書く。** 「1. Leviathan BAN Ivy」のように、ピック・BAN の流れを順番で読ませる（HLTV）。
5. **ヒーローは絵で示す。** 名前だけのタグにしない。スコアボードの選手名の横にヒーローのアイコン（VLR / HLTV）。
6. **数値は等幅・右揃え。** `font-variant-numeric: tabular-nums`、K/D/A は区切りをそろえる。
7. **連番を前面に。** レポートは `#1, #2 …`、大会は `DLNS #65`（Pudding / F1）。
8. **目次は表。** 番号 / 日付 / 大会 / 地域 / 優勝 / スコア（Liquipedia / F1）。
9. **出典を必ず書く。** ページ末尾に、データ元と動画のリンク。

### 禁止事項（ユーザー指定）
- Inter フォント
- 紫のグラデーション（紫そのものもアクセントに使わない）
- 光るボタン（`box-shadow` の発光、ネオン）
- 1語だけイタリックにしたセリフ体の見出し
- 横一列に並んだ4枚の統計カード
- 加えて、前回のレポートで「AI っぽい」と判断したもの：全部を同じ白い角丸カードに入れる／①〜⑤の同じ形のカード／「このページに載せていないこと」のような予防線の節／勝ち青・負けオレンジの初期配色

### 確認
- 幅 375px で、横スクロールが出ない（表は表の中だけでスクロール）、余白 16px、タップ領域 44px 以上。
- ホバーは色か下線の変化だけ。拡大・発光はしない。
- ライト / ダークの両方で読める。

## 3. 確定した方向性：A. スコアシート

元にした参考：**VLR.gg の試合ページ**と **HLTV の試合ページ**。比較した B（ナイトシフト）・C（データ記事）は `mockups.html` に残してある。

### 色（トークン）
| 名前 | ライト | ダーク | 用途 |
|---|---|---|---|
| `--page` | `#cfcfcb` | `#161615` | ページの地（VLR の灰色） |
| `--panel` | `#ffffff` | `#222220` | 白いパネル |
| `--cell` | `#f1f1ef` | `#2c2c2a` | 表の数値セル・マップ帯 |
| `--ink` | `#2b2b2b` | `#e8e8e4` | 本文 |
| `--mute` | `#6b6b6b` | `#9a9a94` | ラベル・補足 |
| `--line` | `#ececec` | `#333331` | 区切り線 |
| `--link` | `#0a7cad` | `#5bb6dd` | リンク・選手名 |
| `--win` | `#2b8a3e` | `#5cc275` | 勝ち（文字色・細い帯のみ） |
| `--lose` | `#c92a2a` | `#ef6b6b` | 負け（文字色のみ） |
| `--hi` | `#e3f1e5` | `#1f3a26` | そのマップの最多セルの背景 |

- 色はデータにだけ使う。勝ちは緑、負けは赤の**文字**で示し、塗りは「最多セル」と「ヒーロー勝敗の帯」だけ。
- パネルは**角丸なし・影なし・枠線なし**。灰色の地との明度差だけで区切る（VLR）。

### 文字
- 数字・スコア・チーム名：**Barlow Semi Condensed**（600 / 700）
- 本文・和文：**IBM Plex Sans JP**（400 / 500 / 700）
- 本文 13px、表 13px、ラベル 11px・太字・大文字・字間 .08em・`--mute`。スコアだけ 40px（375px 幅では 32px）。
- 数値は `tabular-nums`。

### 部品（shadcn/ui を上の色・文字で作り直して使う）
- **Tabs**：マップ切り替え。下線だけで選択を示す（VLR の Overview / Performance タブ）。
- **Table**：スコアボード。セルは `--cell` の箱を 3px 間隔で並べる（VLR）。勝ちチーム・負けチームで表を分ける（HLTV）。
- **Tooltip**：ヒーローアイコンにヒーロー名。
- **Separator**：パネル内の区切り。
- アニメーション（Magic UI）は **NumberTicker（スコアのカウントアップ）** と **BlurFade（パネルの出現、0.3秒以内・移動 6px 以内）** だけ。発光・拡大・跳ねる動きは使わない。`prefers-reduced-motion` では止める。

### レイアウト
- 中央カラム最大 760px、パネル間 12px、パネル内の左右 16px。
- 上から：パンくず（大会名・日付・レポート番号）→ シリーズのスコア → マップ別の勝敗帯 → マップのタブ（ドラフト＋マップ情報の2カラム、スコアボード）→ 大会全体の集計 → 試合の流れ → 持ち帰り → 出典。
- 375px では 2カラムを1カラムに、マップ帯を縦積みに。表は表の中だけで横スクロール。
