# 西本ゆら - ポートフォリオサイト

このリポジトリは、 **西本ゆら** の個人ポートフォリオサイトのソースコードです。

## アーキテクチャ

- **HTML5 & CSS3**: 美しさとスムーズなアニメーションを重視した、完全オリジナルでレスポンシブなデザイン。
- **Vanilla JavaScript**: カスタムカーソルやページ遷移アニメーションなどのインタラクティブな要素に使用。
- **GitHub Pages**: GitHub Pagesでスムーズにホスティングできるように設計されています。

## ディレクトリ構成

- `/css` - メインのスタイルシート (`style.css`)
- `/js` - メインのJavaScriptファイル (`main.js`)
- `/images` - サイト内で使用されているすべての画像ファイル
- `index.html` - ランディングページ / ホーム
- `about.html` - プロフィールおよび経歴
- `projects.html` - プロジェクト一覧
- `project-*.html` - 各プロジェクトのケーススタディ（詳細ページ）
- `contact.html` - お問い合わせ情報
