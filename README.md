# Nishimoto Yura - Portfolio Site

This repository contains the source code for the personal portfolio website of **Nishimoto Yura**, a creative professional involved with REVATI and REVATI Studio.

## Architecture

- **HTML5 & CSS3**: Fully custom, responsive design prioritizing aesthetics and smooth animations.
- **Vanilla JavaScript**: Used for interactive elements, such as the custom cursor and page transition effects.
- **GitHub Pages**: Designed to be hosted seamlessly on GitHub Pages.

## Directory Structure

- `/css` - Contains the main stylesheet (`style.css`)
- `/js` - Contains the main JavaScript file (`main.js`)
- `/images` - Contains all image assets used across the site
- `index.html` - The landing page / Home
- `about.html` - Profile and biography
- `projects.html` - Project index
- `project-*.html` - Individual project case studies
- `contact.html` - Contact information
