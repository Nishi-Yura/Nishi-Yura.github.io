5. 試合の流れ（EDL.GG の記事から）

  • EU Map 1（36分）：合計27キルの低キル戦。終盤の約6分で相手をほぼ全滅させ、そのまま Mid-Boss と Rift を取って勝利。
  • EU Map 2（21分）：Leviathan が 37-14 で快勝。
  • NA Map 1：合計73キル（40-33）。序盤は YFP が強かったが、Cloud9 が終盤に勝ち切った。
  • NA Map 2：YFP が6分前に Guardian を2体壊し、8分で 9-5。
  • NA Map 3：Cloud9 が終盤型のドラフトでジャングルを支配。YFP は7キル。

6. 上達に向けた持ち帰り

① 集団戦のあとはオブジェクトまで

EU Map 1 は、相手をほぼ全滅させた直後に Mid-Boss と Rift まで取って試合を終わらせています。

② 序盤リードは Guardian で形にする

NA Map 2 の YFP は、6分前に Guardian を2体壊して、8分でキル 9-5。以降は Cloud9 を3キルに抑えました。

③ 先行ピックでも安心しない

Lady Geist を取ったチームは3試合すべて負け。先に取ったヒーローより、全体の構成で見ます。

④ 終盤型の構成は序盤負けでも勝てる

NA Map 3 の Cloud9（Wraith・Mirage・Seven など）は、序盤の差を逆転しました。

⑤ BAN は「使われると困るヒーロー」を消す手

Baba は5マップすべてで BAN され、一度も使われていません。Nurse Harrow も、BAN されたマップが4つありました。

自分の試合に当てはめる（直近10戦で数える3点）

  • 集団戦に勝ったあと、オブジェクトを取れた回数
  • 序盤に壊せた Guardian の数
  • 自分のデス数（Cloud9 の average は、この試合で11デスでした）
